# SCL-90 心理健康自测

一个温馨的 SCL-90 心理健康自评量表网页，带有舒缓焦虑的设计风格和因子雷达图。

## 特点

- 90 道 SCL-90 标准题目，9 个因子维度分析
- 因子雷达图可视化（含全国常模参考线）
- 舒缓焦虑的暖色调设计 + 呼吸动画
- 答题过程中的鼓励语
- 温柔的结果解读
- 完全前端运行，数据不上传

## 启用 GitHub Pages

1. 进入仓库 Settings > Pages
2. Build and deployment > Source 选择 **GitHub Actions**
3. 推送代码后会自动部署
