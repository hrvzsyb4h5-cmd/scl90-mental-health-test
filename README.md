# SCL-90 症状自评量表

一个专业、美观的 SCL-90 心理健康自评网页，纯前端单文件实现，包含九维因子雷达图。

## 功能特点

- 90 道 SCL-90 标准题目，五级评分，逐题自动前进
- 结果页：总分、总均分、阳性项目数、阳性症状均分
- 九维因子雷达图（纯 SVG 手绘，离线可用）
- 九张因子详解卡片，按正常/轻度/中度/重度四色分级
- 结果可导出为文本，支持重新测试
- 响应式适配，支持 prefers-reduced-motion
